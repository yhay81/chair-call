# Stack decision

- Cloudflare Workers for the request boundary
- Hono and Hono JSX for routes and semantic HTML
- D1 for short-lived public listings, reports, and anonymous counters
- Cloudflare Rate Limiting for write protection
- Vite+ for development, checks, tests, and builds
- Browser JavaScript for filtering, preview, management fragments, and application messages

Better Auth is omitted because there is no applicant account or server-owned private workspace. A listing creator receives a random management token whose hash is stored server-side.
